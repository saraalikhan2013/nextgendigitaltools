# NextGen Digital – Premium Telegram Community Landing Page

A premium, modern, responsive landing page for **NextGen Digital** stock market learning and trading insights community.

## 🚀 Live Demo & Telegram Channel
- Telegram Channel: [NextGen Digital Chart Scanner](https://t.me/nextgendigitalcharttools)

## 🛠️ Features
- **Modern Fintech Aesthetics**: Dark emerald green theme, subtle financial grid overlay, soft ambient glows.
- **Conversion-Focused Layout**: High-visibility Telegram CTA buttons with smooth hover animations.
- **Clean Typography**: Space Grotesk & Inter font pairing.
- **Glassmorphism Feature Cards**: Highlighting core educational pillars.
- **Fully Responsive**: Mobile-first architecture optimized for Instagram in-app browsers, tablets, and desktops.

## 📦 Project Structure
- `index.html` — Main responsive single-page application.
- `logo.jpg` — Official brand logo asset.
